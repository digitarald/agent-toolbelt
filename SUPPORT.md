# Support

This is a personal project maintained by [@digitarald](https://github.com/digitarald),
not a GitHub-supported product. There is no response-time or compatibility guarantee.

For bugs and questions, search the
[existing issues](https://github.com/digitarald/agent-toolbelt/issues) before
opening one. Include the plugin and version, your host and version, what you
tried, and what happened. Leave out secrets and private code.

Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
